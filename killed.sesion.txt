  ├─────────────────────┼─────────────────────────────────────────────────────────────────────┤                                    
  │ recovery-usage.toml │ Tracks recovery code consumption (not the codes themselves)         │

  1. Go to pypi.org → Account Settings → 2FA → Add security key
